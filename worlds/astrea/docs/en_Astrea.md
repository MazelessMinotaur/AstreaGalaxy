# Astrea: Six-sided Oracles (PC)

## Where is the options page?

The [player options page for this game](../player-options) contains all the options you need to configure and export a
config file.

## What does randomization do to this game?

All rewards for fights (dice choices, blessings from hard/boss fights) are randomized across the archipelago.
Non battle nodes are currently not randomized, they give what they say they will and appear normally.

## What is the goal of Astrea?

The goals for an archipelago of Astrea is either to win a single run
or win a set number of runs with pre-chosen oracles.
A win can either be to reach Astrea's heart (base difficulty)
or purify Astrea (Astrea difficult 1+)

## What are the locations in Astrea?

The main locations in Astrea are the battles.
After completing each battle a number of locations equal to the number of items that battle
would normally rewardn the player with is checked

There are optional locations for an "Archipelago die".
If enabled, at the start of the run, the player will get a forge of an "Archipelago item".
This die face must be rolled and cast to grant the items from the this pool.

## When the player receives an item, what happens?

Items won't be received until after the current or next battle is won.
The player will then receive all pending items.

## What happens if a player dies in a run?

The player will have to start a new run from the beginning, 
however this next run is likely going to be easier as they will have addtional resources starting after the first fight
Battles already won will not count as new locations.
